iBatcher

Универсальный массовый запуск REST-запросов · v__APP_VERSION__

Профиль

Сохраните настройки документа без паролей

1. Вход в систему

Необязательный запрос, выполняется один раз перед прогоном

2. Основной запрос

Запрос, который будет повторён указанное количество раз

3. Динамические поля

Оставьте список пустым, если тело всегда одинаковое

Путь в JSONГенераторПараметр
Динамических полей нет — JSON будет отправляться без изменений.
Примеры путей: $.sbpFpMessageId, $.payment.operationId, $.items[0].id

4. Проверка ответа

Значения подходят для стандартных ответов создания документов ДБО

При наличии поля ошибки ответ считается ошибочным даже с HTTP 200. Очистите «Подтверждение успеха», если для API достаточно статуса HTTP 2xx.

Запуск

Сначала рекомендуется один проверочный запрос

Проверочный запрос создаёт реальный документ и входит в общее количество.
Для нового входа укажите пароль в разделе «Вход в систему». Настройки прогона берутся из сохранённого состояния.
